# AML-3303 — Project files

This repository contains weekly exercises for AML-3303 (Software Tools and Emerging).

Below is a concise summary of the weekly folders and their primary contents

## Week 1
- `SDLC_Principles.py` — short script working with IRIS dataset and doing some basic actions

## Week 4
- `RAG.ipynb` — Jupyter notebook for Retrieval-Augmented Generation (RAG) exercises.
- `RAG.py` — Same content as RAG.ipynb, but is used for running streamlit app

## Week 6
- `multithreading.py` — examples demonstrating Python multithreading patterns.
- `polars_vs_pandas.py` — comparisons between Polars and Pandas performance/APIs.

## Week 7
- `ci.yml` — CI configuration (GitHub Actions) used in course exercises.
- `drift_check.py` — script for model/data drift checks.
- `mlflow_activity.py` — script that logs experiments to MLflow.
